# Memory Match Game

## Description
Memory Match is a simple browser based game where the player flips cards to find matching pairs, he game tracks the number of moves and allows restarting at any time, it is designed to practice front end web development skills using HTML, CSS, and JavaScript

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Play
1. Open `index.html` in a web browser.
2. Click on any two cards to flip them.
3. If the cards match, they stay revealed.
4. If they don’t match, they flip back after a short delay.
5. Continue matching pairs until all cards are revealed.
6. Track your moves using the counter displayed below the game board.
7. Click the “Restart Game” button to play again.


## Challenges & Learning
During this project, I encountered several challenges:  
- **Card flipping logic**: Ensuring that only two cards could be flipped at a time and that unmatched cards would flip back correctly.  
- **Game state management**: Keeping track of first and second card selections, moves, and locking the board during animations.  
- **Responsive layout**: Designing a simple grid layout that would look consistent across different screen sizes.
  
I learned: Different platforms for running web based systems and actaul basic programming
